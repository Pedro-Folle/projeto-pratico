# projeto-pratico

Funcionalidade: Notificação Automática de Vencimento de Contratos

Versionamento Semântico

Oque é:

Cada vez que o projeto sofre uma alteração será lançada uma nova versão, esse número muda de um jeito que já dá pra entender se foi uma mudança grande, uma coisa nova que foi adicionada, ou só uma correção de erro (bug).

O significado de MAJOR.MINOR.PATCH e Quando cada número muda

MAJOR: aumenta quando é feita uma mudança grande no sistema, que muda como ele funciona e pode quebrar coisas que já existiam antes. Tipo mudar totalmente uma funcionalidade.
MINOR: aumenta quando é adicionada uma funcionalidade nova, mas sem estragar o que já tava funcionando antes.
PATCH: aumenta quando é só uma correção de bug, sem adicionar nada novo, só consertando algo que tava errado.
